# [Expanded Object Tracking] Gaussian Process-Based Three-Dimensional Extended Object Tracking and Shape Learning [with MATLAB Code]

Introduction: Target tracking can be described as inferring the unknown kinematic properties of a target using sequentially available sensor data. When an object of interest is relatively small and may occupy a single unit of a sensor device, this problem is explicitly referred to as point object tracking. In such cases, the number of measurements returned by the object is limited to one per scan. On the other hand, when the resolution of the sensor is sufficient relative to the size of the object, it is known as extended object tracking (EOT), allowing it to be detected by several sensor units. Therefore, in this setup, the object may initiate multiple measurements during a single scan.
There is a vast literature on EOT problems, especially in 2-D space (see [1] for a comprehensive survey). Such methods handle 2-D measurements by relying on various range models. These degree representations exhibit significant differences in compactness and expressiveness. For example, a set of EOT algorithms impose simple geometric shape models, such as circles, rectangles, or ellipses [2]-[8]. These essentially implement degree modeling, with only a limited potential for cost-effective shape descriptions. In another research area, the random hypersurface model (RHM) provides a more flexible range representation for spherical objects [9], [10]. This model is based on Fourier series expansions over spatial ranges, along with coefficient extensions and motion. Similarly, the potential range of spherical objects is described by Gaussian processes (GP) in [11] and [12]. The model has good analytical performance and a close connection to Bayesian formulations, effectively estimating object pose and shape. Several adaptations have been studied for various application environments [13]-[20].
On the other hand, attempts to solve EOT problems in 3D space are rare, despite the increasing availability of 3D data through sensors such as depth cameras and LIDAR. Moreover, most of these attempts are direct summaries of basic geometric models, represented by ranges using, for example, ellipses or bounding boxes. One exception to this is proposed in [21], which aims at a more general range description. The method assumes that three-dimensional object surfaces can be constructed via some transformations, such as translations and rotations of planar curves. It then employs the RHM concept to derive a generic tracking framework. This approach requires a special recipe of recursive estimations, taking into account specific transformations. However, the prior knowledge about object shape may not be available for standard tracking applications.
Another branch of research avoids the application of parametric shape descriptions; instead, it bases on point cloud representations of shapes, formed by collecting measurements over time [22]-[24]. These methods facilitate joint tracking and shape learning for arbitrary objects when continuous, high-precision, and informative measurement data is available. However, they suffer from robustness issues due to sparseness caused by factors such as increased distance, changes in Vantage position, and occlusions. Additionally, storage and computational requirements scale with the size of the object's range.
Research on the 3-D object tracking problem under this issue. 3-D measurement results carry a wealth of information, not only conveying clues about kinematics but also naturally revealing the characteristics of the object's range. However, estimating an unknown shape from noisy point cloud data is a challenging task, and the problem becomes even more severe when the object is in motion. This is mainly due to the inherent interdependence between pose description and shape description. Therefore, a reliable estimation requires precise information about the other. Considering this, we formulate the problem as joint estimation of kinematics and shape variables within a unified framework. For the description of object range, we adopt a Gaussian Process (GP) based method that facilitates flexible representation and has good analytical properties. In this paper, we significantly expand our previous work on 3-D object tracking [25]. Specifically, these contributions can be listed as follows.
1) We propose two new probability representations for 3-D degree. The first method represents the unknown three-dimensional surface in spherical coordinates using a radial function. The second method utilizes the correspondence between the three-dimensional shape and its projections on multiple planes, thereby characterizing the original three-dimensional surface through the set of contours of these projections. Probability shape representation is realized by GP modeling of the above description without imposing any parametric form. By doing so, we obtain a flexible foundation for estimating various shapes.
2) This approach enables us to handle unknown degrees within a Bayesian framework, allowing the posterior distribution to provide analytical expressions for object shape with well-defined confidence intervals, and easily incorporate any available prior information.
3) We develop a measurement model to express the relationship between point measurements and object range, using an effective approximate GP regression.
4) Kinematics and object range are effectively inferred by extending Kalman Filter (EKF) with respect to a unified state space model.
5) Utilize unit quaternions to describe the orientation of targets, and derive a new rotational motion model for effectively estimating the full three-dimensional orientation and angular rate of targets.
Article illustrations
Conclusion proposes a novel method to facilitate perception in autonomous systems. The algorithm can process three-dimensional point cloud data, tracking dynamic targets with unknown shapes. This method fully leverages the potential of information hidden in sparse point cloud measurements by estimating the shape of an object and its motion state, including position, velocity, and direction. The proposed model is flexible in expressing and learning various shapes that may coexist within a surveillance area. Another effective implementation method also comes from reducing computational demands by utilizing planar projection. The algorithm is effective in implementation, making it possible to extend to multi-object tracking frameworks and real-time applications. These methods provide analytical expressions for object shape analysis, which can be used later for online recognition and classification purposes. By using negative information embedded in point measurements, considering alternative covariance functions and inference methods, and incorporating a dedicated model with a proportional factor in prediction, the performance of the suggested method can be further improved. The method is applicable to various domains that require accurate perception, such as robotic applications where mobile agents need to navigate in a 3-D environment with 3-D motion constraints or offline applications like 3-D map extraction.
